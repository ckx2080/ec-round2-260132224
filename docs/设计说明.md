## 2. 插补算法与参数

**结构**：1ms 时基置标志 → 主循环 5ms 执行一次插补（200Hz）→ 写 CCR。

**多轴同步（归一化）**：每轴按自身 `v_max / a_max` 计算走完全程所需时间 `t_i`，取 `T = max(t_i)`，再把各轴时间轴按 `T` 拉伸，实现同起同停。

| 参数 | 底座 q1 | 肩 q2 | 肘 q3 | 夹爪 q4 | 单位 |
|---|---|---|---|---|---|
| 行程 `[q_min, q_max]` |  |  |  |  | 0.1° |
| 最大角速度 `v_max` |  |  |  |  | °/s |
| 最大角加速度 `a_max` |  |  |  |  | °/s² |
| 控制周期 | 5 | | | | ms |
| 速度规划 | 梯形（可选 S 曲线） | | | | |

**脉宽映射**：`pulse_us = 500 + q_deg × 2000 / 180`，计时器 2MHz 计数，`CCR = pulse_us × 2`（0.5µs 分辨率）。

## 3. 关键取舍

| 取舍 | 选择 | 理由 |
|---|---|---|
| 优先级划分 | 1ms 时基 > 5ms 插补 > 20–50Hz 上报 > 串口打印 | 控制节拍不能被通信阻塞 |
| USB 发送 | 缓冲满丢最旧帧，不阻塞 | 掉一帧状态不影响控制，卡一拍会甩关节 |
| I²C 失败 | 1s 内停输出 + 置故障位 | 任务书 3.1 T4 硬性要求 |
| 传感器安装 | 小臂末端 | 直接反映末端俯仰 |
| 结构 | 短臂轻量化 | SG90 扭力有限，末端越轻重复精度越好 |
